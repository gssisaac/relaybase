# Relaybase 0.1.6

Pairs with Worker install bundle **0.1.3**.

## Highlights
- Email Routing self-heal after Worker install and from the Domains dashboard
- Fix desktop dev reload loops when Duck Launcher already runs the Next.js app

## Changes
- Auto-repair disabled Email Routing rules for all domains after Worker deploy
- Domains dashboard shows routing health and a manual Repair routing action
- Reuse an existing Next.js dev server in Duck Launcher instead of spawning duplicates
- Wait for Tauri invoke before session boot to avoid startup race errors
