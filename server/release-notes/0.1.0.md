# Relaybase Worker 0.1.0

## Highlights
- First public Worker install ZIP for customer Cloudflare accounts
- Desktop auto-install deploys D1, R2, and the routing Worker without npm install
- Inbox, compose, audience, and broadcasts run on the installed Worker

## Changes
- Initial customer install bundle (`worker.js` + `wrangler.toml`)
- D1 schema via `POST /console/init-db` (empty) and `POST /console/migrate-db` (existing)
- Mail atoms in R2 (`inbound|sent {domain}/{id}/`) with D1 `RELAYBASE_MAIL` search index
- Settings Worker update downloads this ZIP and re-deploys without replacing D1
