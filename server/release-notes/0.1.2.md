# Relaybase Worker 0.1.2

## Highlights
- Worker `CF_ACCOUNT_ID` is optional — domain / DNS / sending health use `CF_API_TOKEN` only
- Discover account id from `GET /zones` (`account.id` on the zone), not a required secret
- Forgot-passtoken reset and Worker upgrade (`migrate-db`) accept Cloudflare OAuth account proof

## Changes
- `mailApiReady` / Enable email API verify do not require Worker `accountId`
- `createCloudflareClient` requires `CF_API_TOKEN` only; list zones without `account.id` filter
- Resolve account id: env → D1 `owner_config.cf_account_id` → zone `account.id` → `GET /accounts`
- `POST /console/reset-admin` accepts `cfAccessToken`; `init-db` / `migrate-db` accept `X-Cf-Access-Token`
