# Relaybase 0.1.7

Pairs with Worker install bundle **0.1.4**.

## Highlights
- Fix frequent Cloudflare re-authentication caused by refresh-token invalidation on transient errors
- Streamlined Worker updates run in the background without extra approval screens
- Live send status on the Sent list with full sent-message bodies

## Changes
- Stop wiping a valid CF OAuth refresh token on any HTTP 400 response
- Worker update: skip approve/confirm screens and run download/deploy in the background
- Recheck for desktop and Worker updates on route change via a new stale scheduler
- Remove pre-launch legacy unscoped keyring fallback
- Show live send status on the Sent list; render full sent-message bodies
- Remove Google Workspace subdomain coexistence from website docs
