# Relaybase Worker 0.1.1

## Highlights
- Fixes desktop auto-install failing at migrate-db with 401 Unauthorized
- Install-time schema endpoints use AUTH_PEPPER bootstrap instead of ADMIN_TOKEN

## Changes
- `POST /console/init-db`, `/console/migrate-db`, and `/console/setup-admin` accept `X-Auth-Pepper` when no owner is configured yet
- Owner passtoken + scoped sessions replace the retired ADMIN_TOKEN god token on the product Worker
- Settings Worker update still reuses existing AUTH_PEPPER and D1 bindings
