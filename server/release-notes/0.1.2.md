# Relaybase Worker 0.1.2

## Highlights
- Forgot-passtoken reset proves Cloudflare OAuth by `GET /accounts/{CF_ACCOUNT_ID}`
- Worker upgrade (`migrate-db`) uses the same OAuth account proof when an owner already exists

## Changes
- `POST /console/reset-admin` accepts a Cloudflare OAuth access token (`cfAccessToken`) and requires `CF_ACCOUNT_ID`
- `verifyCfTokenAccount` calls `GET /accounts/{CF_ACCOUNT_ID}` (`success === true`)
- `POST /console/init-db` and `/console/migrate-db` accept `X-Cf-Access-Token` with the same proof
