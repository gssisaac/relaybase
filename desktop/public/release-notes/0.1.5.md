# Relaybase 0.1.5

Pairs with Worker install bundle **0.1.2**.

## Highlights
- Mail accounts and drafts survive sign-out and sign-in again

## Changes
- Replace single `workspace.json` with a `workspaces.json` keymap that persists `scopeId` per workspace
- Stop clearing workspace config on owner sign-out so desktop data stays in the same scope directory
- Migrate existing `workspace.json` entries to the new format on first launch
