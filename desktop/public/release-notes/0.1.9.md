# Relaybase 0.1.9

Pairs with Worker install bundle **0.1.6**.

## Highlights
- Web owner console: full dashboard, Cloudflare OAuth auto-install, and Worker updates in the browser
- Cross-device sidebar, UI, and draft persistence via the Worker
- Mailbox-mode desktop updates stay at or below the connected Worker’s desktop ceiling

## Changes
- Add web Cloudflare OAuth auto-install (popup flow, configurable redirect, reuse after Back)
- Give web owners full console and dashboard access, matching desktop
- Show Worker update in the web console; hide Desktop update on web
- Wire team web mail to the shared UI and Worker `/mobile/*` APIs
- Persist sidebar/UI/draft state to Worker `account_state` for web parity
- Preserve Worker secrets on redeploy and allow same-version reinstall
- Gate mailbox-mode desktop updates against Worker `DESKTOP_VERSION`
- Show global Worker install status in the sidebar
- Allow text selection in mail detail and copy full sender addresses
- Trust user confirmation for CF API token setup when the probe disagrees
- Add mobile shell navigation, responsive console tables, and full-width web layout
