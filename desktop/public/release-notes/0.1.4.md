# Relaybase 0.1.4

Pairs with Worker install bundle **0.1.2**.

## Highlights
- Stricter Cloudflare API token checks (Email Routing, DNS, Edit, Email Sending) with clearer setup errors
- Google Workspace MX conflict guidance during domain onboarding
- Direct Mac downloads on the site without an email signup
- Settings shortcuts to the Cloudflare dashboard

## Changes
- Probe token permissions at connect time and show structured missing-permission errors
- Surface Google Workspace MX conflicts when adding a domain
- Add Google Workspace coexistence guide and landing FAQ
- Persist workspace connection and resolve Cloudflare account ID via user_data
- Improve email API setup guidance and verification feedback
- Enable direct DMG downloads with optional device tracking
