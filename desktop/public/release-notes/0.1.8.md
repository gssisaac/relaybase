- Plain-text emails now render as text instead of being wrapped in an iframe
- Cloudflare Email Routing drift detection with dashboard deep links

- Surface Cloudflare Email Routing drift and add dashboard deep links
- Add passkey gate to hq/admin (login, session middleware, app shell)
