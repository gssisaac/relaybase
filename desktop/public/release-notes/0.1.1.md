# Relaybase 0.1.1

First public release.

## Highlights
- Guided Cloudflare install — deploy the Worker, create storage, set up owner passtoken
- macOS desktop app (Apple Silicon) with in-app Worker update
- Email + dashboard in one app

## Changes
- Setup Rollback deletes Worker, D1, and R2 — fails if anything remains
- Owner passtoken in OS keyring; Touch ID read-gate for console unlock
- Settings → Worker update reuses OAuth and runs `migrate-db` on existing installs
